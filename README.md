# Geospatial Data Analysis Projects

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://python.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

10 professional geospatial analysis projects addressing real-world African development challenges — from disaster response to food security, each producing publication-quality maps and actionable insights.

---

## Projects

| # | Project | Domain | Techniques |
|---|---------|--------|-----------|
| 1 | Urban Heat Island Mapping | Climate | LST analysis, K-Means zoning |
| 2 | Flood Risk Zone Mapping | Disaster | DEM analysis, Random Forest |
| 3 | Healthcare Access Gap | Public Health | Travel-time modelling, K-Means |
| 4 | Deforestation Monitoring | Environment | NDVI time-series, change detection |
| 5 | Road Accident Hotspots | Safety | KDE, DBSCAN clustering |
| 6 | Crop Yield Prediction | Agriculture | NDVI/EVI, LightGBM |
| 7 | Water Quality Mapping | WASH | WHO compliance, Random Forest |
| 8 | Conflict Incident Mapping | Security | ACLED analysis, KDE hotspots |
| 9 | Electricity Grid Risk | Infrastructure | XGBoost, network analysis |
| 10 | Food Security Dashboard | Nutrition | IPC classification, market data |

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Geospatial | GeoPandas, Folium, Shapely, Rasterio |
| Machine Learning | scikit-learn, LightGBM |
| Remote Sensing | Sentinel-2, Landsat-8 NDVI/EVI |
| Visualisation | Matplotlib, Seaborn, Plotly |
| Data | pandas, NumPy |

---

## Quick Start

```bash
git clone https://github.com/Momahmoses/geospatial-analysis-projects.git
cd geospatial-analysis-projects
pip install -r requirements.txt
# Navigate to any project folder and run main.py
```
